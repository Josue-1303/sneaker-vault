
# Sneaker Vault

A cinematic and responsive sneaker showcase built around
a personal collection of 12 selected sneakers.

## Project Information

- Developer: Josue Morales
- Project: Sneaker Vault
- Version: 0.1
- Started: November 2026
- Status: In development

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON

## Features

- Responsive design
- Dynamic product pages
- Product collection
- Brand filters
- Availability filters
- Price sorting
- Individual product color themes
- CSS animations
- Sneaker availability monitoring (planned)
